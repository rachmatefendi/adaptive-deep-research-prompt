# Use case 07 — AFGS/MDGR governance research (reference-only)

**Purpose:** Explicitly request the optional AFGS/MDGR overlay without inferring implementation or governance approval.

## Ready-to-paste research brief

Use with [`PROMPT.md`](../PROMPT.md).

```text
RESEARCH TOPIC:
Research-level comparison of AFGS/MDGR governance concepts
and relevant patterns for evidence, authority, policy constraints,
and controlled execution in AI-enabled enterprise workflows.

Research Objective:
Evaluate conceptual alignment, implementation dependencies,
evidence sufficiency, authority boundaries, and failure modes.
Preserve all provided frozen normative baselines unchanged.

Research Context:
AFGS/MDGR material is a referenced governance framework.
Any official normative specification must be supplied or
retrieved from an authorized source; do not reconstruct it
from memory or extrapolate unspecified components.

Expected Outcome: TECHNICAL
Target Audience: ENGINEERS
Research Depth: COMPREHENSIVE
Output Language: ENGLISH
Writing Style: TECHNICAL
Evidence Standard: HIGH-ASSURANCE RESEARCH
Governance Profile: AFGS_MDGR_REFERENCE
Deliverable Format: TECHNICAL REPORT

Additional Requirements:
Distinguish conceptual guidance, normative statements,
implemented controls, tested results, and external validation.
Never claim formal MDGR verdicts, authorized deployment,
GEG enforcement, SC2/SC3 conformance, or changes to a
frozen baseline unless demonstrably evidenced.
Research is not an implementation mandate.
```

## Expected output characteristics

A source-constrained reference analysis with explicitly scoped terms, authority boundaries, no silent baseline changes, and separate lists for conceptual gaps versus observed implementation defects.

**Critical watch-out:** Without normative source documents, the report must qualify the AFGS/MDGR-specific claims. The overlay is not a universal governance module.
